# 🚕 TaxiPark - Frontend

A responsive taxi booking web application frontend built with HTML, CSS, JavaScript, Bootstrap, and Slick Slider. It interacts seamlessly with the Django backend API for ride bookings.

## 🌟 Features
- 📱 Fully Responsive Design (Bootstrap)
- 🚖 Interactive Booking Form with AJAX/Fetch API
- 🔄 Dynamic UI notifications for success/error handling
- 🎠 Carousel display for services and testimonials

## 🚀 Getting Started

You only need a modern web browser (Google Chrome, Mozilla Firefox, Edge, etc.).
